# 公開サイトとリポジトリの反映経路

確認日: 2026-08-25

- `https://aquira.art` の応答からは、ページタイトルとして `Aquira1978.com | Aquira` が返った。
- リポジトリ `aquirae-bit/aquira-art` の生成元では、`https://www.aquira.art/` を正規URLとする静的HTMLを生成している。
- 既存の `HOMEPAGE_REVIEW_2026-08-25.md` は、公開先がWixであり、リポジトリのコミットだけでは公開サイトを置換しないことを記録している。
- したがって本リポジトリでは、静的サイトを安全に保守・検証・公開準備できる状態へ整備する。実ドメインへの反映には、ホスティング切替またはWix側の同等再構築という別途の公開判断が必要である。

この記録は、コード上の改善と公開サイトの反映を混同しないための運用上の基準とする。
